Codigo: Sistema de Gestion de Bibliotecas
El codigo en python implementa un sistema de gestion de biblioteca utilizando programacion orientada a objetos. Se incluyen 5 clases
La primera clase pertenece a Libro, donde los atributos son titulo, autor , Isbn, editorial, año de publicacion y si se encuentra disponible. Para esta clase se uso el constructor de la clase (init), 
mostrar info del libro y actualizar disponibilidad.
Para la clase 2, (usuario), los atributos son id del usuario, nombre, email y libros prestados. Los metodos que se usaron para esta clase es el constructor de la clase init, prestar libro y devolver libro
En la clase 3 (Bibliotecario), los atributos son el id del bibliotecario y el nombre, los metodos son el constructor init, añadir libro, eliminar libro 
y buscar libro
Para la clase 4 (biblioteca) los atributos son libros, usuarios y bibliotecarios. Los metodos para esa clase son el constructor init, registrar usuario, eliminar usuario, listar usuario
y listar libros
Para la clase 5 (material) que es la clase base tiene atributos como titulo y autor y como metodo, mostrar_info_basica(). La clase Persona representa a cualquier persona que interactue con la biblioteca. Tiene como
atributos id de la persona, el nombre y su email. La heredan las clases usuario y bibliotecario

Las funcionalidades que tiene el programa son registrar usuarios y bibliotecarios, añadir nuevos libros al sistema, 
prestar libros disponibles a los usuarios registrados, devolver libros prestados, evaluar cada libro si esta disponible o no. Esas son
las funciones como tal con las que cuenta el programa
